# Find Mate Service API

API-сервис для поиска компаньонов (Find Mate). Построен на **FastAPI** с использованием **PostgreSQL**, **SQLAlchemy** и **JWT-аутентификации**.

## Технологии
- Python 3.11+
- FastAPI
- PostgreSQL
- SQLAlchemy (ORM)
- Pydantic (валидация)
- Python-JOSE (JWT)
- Passlib (хеширование паролей)

## Основные возможности
- Регистрация и аутентификация пользователей (JWT)
- Поиск и фильтрация пользователей по параметрам
- Управление профилями
- Система лайков/матчей (базовая логика знакомств)
- Административная панель (FastAPI Admin)
- Docker-контейнеризация
